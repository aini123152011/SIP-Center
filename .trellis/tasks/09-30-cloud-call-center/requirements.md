# 详细需求规格（requirements.md）v0.1

> `prd.md` 的功能细化，M1-M4 开发的直接输入。标记约定：【默认】= 按行业惯例预设、可推翻；【待定】= 需要用户决策，汇总见 §8。

## 1. 角色与权限模型

| 角色 | 所属 | 职责 | 关键权限 |
|---|---|---|---|
| 平台超管 | 平台侧 | 租户开通/套餐/License/平台线路池 | 全部租户数据（仅管理面） |
| 租户管理员 | 租户 | 组织/坐席/线路/IVR/话术/计费查询 | 本租户全量 |
| 销售主管（班长） | 租户 | 名单分配/监控/监听强插/绩效 | 本部门+技能组 |
| 坐席 | 租户 | 接打电话/客户跟进/下单 | 本人客户与通话数据 |
| 质检员 | 租户 | 质检任务/评分/申诉处理 | 质检范围数据 |
| 财务 | 租户 | 收款/退款/对账/开票 | 财务与订单只读+操作 |
| 仓库/物流员 | 租户 | 发货/物流跟踪 | 订单发货相关 |
| 集成应用 | 平台/租户 | OpenAPI 调用 | 按 AppKey+签名+租户隔离 |

- 权限模型：RBAC（JeecgBoot 原生）+ 数据权限（租户 → 部门 → 个人三级）；按钮级权限沿用 JeecgBoot。
- 坐席账号与系统用户合一：一个用户可有坐席属性（分机/技能组）。

## 2. 语音域

### 2.1 坐席状态机
- 状态集：`离线 → 就绪 ⇄ 小休(子类型：休息/会议/用餐/培训) → 拨号中/振铃 → 通话中 → 话后处理(ACW)`
- 转移：通话结束自动进 ACW，ACW 时长【默认 120s】可配，超时自动回就绪；班长可强制改状态。
- 全状态流转落库（含时间戳），支撑绩效统计与坐席利用率报表。

### 2.2 ACD 排队
- 路由：技能组 + 技能等级；分配策略【默认 空闲最长优先，可切换 轮询】。
- 队列：位置播报/等待音乐；最大排队数【默认 50】、最大等待【默认 300s】，超时溢出动作可配（转其他组/留言/承诺回呼）。
- VIP 插队：客户标签命中则提升优先级。

### 2.3 IVR
- v1 节点类型：欢迎语 / 按键菜单(DTMF) / 时间段路由 / 播放提示音 / 转技能组 / 转外线 / 转机器人 / 留言 / 挂机。
- 数据驱动条件节点（如按客户归属分流）【v2】。
- IVR 流程版本化，可视化编辑器（Vue 前端 + DSL JSON 存储）。

### 2.4 软电话功能矩阵
签入签出（WebRTC 分机绑定）/ 就绪小休切换 / 点击外呼 / 接听挂断保持恢复 / 盲转-咨询转-三方 / 静音 / DTMF / 弹屏联动 / 通话历史。断线自动重签【默认 3 次退避】。

### 2.5 录音与话单
- 录音：全量双向混音；保留期【默认 12 个月，租户可配】；下载需权限且入审计。
- 话单字段：主被叫、号码归属地、坐席、技能组、外呼任务ID、振铃/接通/结束时间、时长、挂断方、disposition（接通/无人接/关机/停机/拒接/忙线/空号）、录音URL。
- disposition 由 voice-plane 基于 SIP 响应码与媒体事件归一化产出。

### 2.6 实时监控
大屏：组级在线数/通话中/排队数/今日接通率/弃呼率；班长操作：监听/耳语/强插/强拆/强制置忙。

## 3. 外呼域

### 3.1 外呼任务生命周期
`草稿 → （可选审核）→ 运行中 ⇄ 暂停 → 完成 / 终止`
任务参数：名单集、外呼模式、并发上限、时段窗口【默认 9:00-20:00 硬限制】、重拨规则、弃呼率阈值、目标技能组/坐席范围、机器人/人工标志。

### 3.2 名单状态机
`未呼 → 呼叫中 → 已接通(→跟进中→已成交 / 无意向) ；未接通 → 按重拨矩阵回队 → 无效终态`
重拨矩阵按 disposition 配置【默认：无人接 3 次/间隔 2h；关机 2 次/间隔 24h；拒接 1 次；空号停机直接终态】。

### 3.3 四模式行为定义
- **手动**：坐席在客户页/工作台点拨，不走任务。
- **预览**：系统推送名单→坐席看资料→拨打/跳过，连续跳过上限【默认 3 次】强制休息。
- **progressive**：固定倍率拨号【默认 1:2】，接通无空闲坐席则进排队。
- **predictive**：目标=坐席利用率最大化；输入=实时滑动窗口（坐席空闲率/接通率/平均通话/ACW）；弃呼率护栏【默认 ≤3%，超限自动降速】，冷启动保守倍率【默认 1:1】。

### 3.4 合规环（强制前置，策略不可绕过）
黑名单（平台级/租户级/批量导入，即时生效）；频控：同号 N 天内不重复外呼【默认 7 天】、单号单日上限【默认 3 次】；投诉名单一键停呼；时段窗口硬限制。每次拨号前同步校验，拦截原因落库可审计。

## 4. AI 域

### 4.1 外呼机器人
- 话术 DSL 节点：开场白 / 意图分支 / 变量采集 / 知识问答(LLM) / 转人工 / 礼貌挂机；流程版本发布 + 沙箱试听。
- 全局参数：打断灵敏度【默认 中】；静音超时【默认 8s 播引导语】；未识别重试上限【默认 2 次后转人工】。
- 意图识别：关键词规则 + LLM 分类兜底；通话结束自动意向打标 A-E【规则可配】。
- 转人工：客户主动要求/负向情绪/关键意图命中 → 呼叫携对话上下文进 ACD 优先队列。

### 4.2 实时转写与坐席辅助
双声道分离转写（客户/坐席独立通道），字幕端到端延迟目标 <1s；坐席辅助 v1：命中关键词推送话术卡；敏感词实时预警（坐席+班长同屏）。

### 4.3 智能质检
- 评分维度【默认，租户可调】：开场白完整性 / 服务禁语 / 超范围承诺 / 情绪异常 / 流程动作（是否介绍优惠、是否确认信息）。
- 引擎：规则（词表/正则/静音时长/语速/抢话）+ LLM 语义评分，双轨加权。
- 流程：全量或抽样（按比例/按标记）→ 自动评分 → 人工复检 → 坐席申诉 → 复检终审。
- 报表：违规类型 Top、坐席得分排名、趋势对比。

## 5. 业务域

### 5.1 客户管理
- 档案：基本信息 / 多联系方式 / 归属（坐席或公海）/ 标签 / 来源（渠道+外呼任务）/ 租户自定义字段（KV 配置化）。
- 查重：手机号租户内唯一；导入时按策略跳重/覆盖【默认 跳重并出报告】。
- 保护与回收：个人保护期【默认 7 天】；公海回收：超期未跟进【默认 7 天】、超期未成交【默认 30 天】。
- 公海：按小组划分池；领取上限【默认 200】；每日领取上限【默认 20】；回收任务每日凌晨批处理。

### 5.2 产品管理
SPU/SKU 两级；多价格（标准价/活动价，按生效时段）；上下架；库存 v1 简单模式（总量+订单锁定，单仓）【多仓 待定→默认 v1 单仓】。

### 5.3 订单管理
- 支付模式（P-01 已确认 2026-10-01）：**三种全支持**——在线支付（微信/支付宝聚合）、货到付款 COD、线下转账+凭证上传。
- 状态机按支付模式分支：
  - 在线支付：`已创建 → 待发货（支付回调成功自动流转）→ 已发货 → 已签收 → 交易完成`
  - COD：`已创建 → 待发货（创建即生效）→ 已发货 → 已签收（签收触发回款登记）→ 交易完成`
  - 线下转账：`已创建 → 待财务确认（客户/坐席上传凭证）→ 待发货（财务核销确认）→ 已发货 → 已签收 → 交易完成`
  - 公共终态：`交易完成 / 售后（退换）/ 已取消`。
- 取消规则：已发货前坐席可取消（按权限），已发货一律走售后退货流程。
- 订单归属：客户 + 来源坐席（外呼任务/通话 ID 关联，支撑归因）。
- 发货：拣货单/发货单，快递单号回填，轨迹订阅回传更新订单状态。
- 销售提成模块【待定 P-02 → 默认 v1 只出业绩报表，不做提成计算】。

### 5.4 财务
收款登记与订单核销；退款单【默认 1 级审批】；对账 v1 简化：支付渠道流水手动导入比对【自动对账 v2】；开票 v1 仅做开票登记台账，金税对接【待定 P-04 → 默认 v2】。

### 5.5 业务报表
成交漏斗（外呼→接通→意向→订单）；坐席业绩排名；产品销量；退款率；来源渠道 ROI。

## 6. 平台域

- 租户生命周期：创建 → 初始化（套餐/线路池分配/管理员账号）→ 使用 → 停用 → 注销（数据导出与删除策略）。
- 套餐计量项：坐席数 / 并发数 / 录音存储 / 通话分钟 / AI 功能开关 / 线路资源。
- 配额超限行为：软限（提示）与硬限（禁止新建外呼任务）组合【待定 P-03 → 默认 并发坐席超限=硬限，存储超限=软限】。
- License（私有化）：机器码=硬件指纹哈希；授权项=坐席数/并发/功能开关/有效期；离线激活文件；到期降级策略（停新业务不停通话）。
- 审计日志：登录/权限变更/数据导出/删除类操作全记录，保留【默认 180 天】。

## 7. 非功能需求

| 维度 | 指标 |
|---|---|
| 并发 | 200 并发通话（M1 压测基线），架构预留横向扩展 |
| 延迟 | 接通→弹屏 P99 <1s；机器人应答 P90 ≤1.5s；字幕 <1s |
| 可用性 | 语音域 99.9%（FS 故障会话不丢目标），业务域 v1 99.5% |
| 安全 | 全链路 TLS；越权用例（跨租户）全覆盖；录音存储加密【待定 P-05 → 默认 v2】 |
| 审计/合规 | §3.4 合规环 + 录音留存 + 审计日志 |
